# Memory Index

Durable notes for AI agents. Commit repo memory with your project.

## How agents should use this

1. Read this INDEX first, then relevant notes under context/, patterns/, decisions/.
2. Before repeating a kind of work, read `patterns/remember-teaching.md` and search MemPalace rooms `jobs` and `corrections` in wing `truedeck-09d5b6c7`.
3. When the user teaches a job or corrects a method, file it in MemPalace (see that note) and write a short markdown note here.
4. Session logs go under sessions/ (optional to commit).
