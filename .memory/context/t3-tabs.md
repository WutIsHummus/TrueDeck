# T3 status on TrueDeck tabs (2026-10-09)

Port T3's thread status into TrueDeck tabs. Do not embed the T3 web app.

- Working / Wait / Done come from coding-agent-adapters terminal patterns, plus a 20s quiet stop.
- Assign a task to a swarm, or to one agent that is not waiting and not working.
- The old T3 webview (`t3-pane`, palette agent `t3`) is removed.
